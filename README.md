# Crystal Clicker 

**Crystal Clicker** is a fast-paced, web-based hybrid game that blends idle clicker mechanics with escalating tower defense strategy. Designed with pure Vanilla JavaScript and styled using modern CSS glassmorphism, the game challenges players to protect a glowing central crystal core against relentless waves of invading enemies.

<img width="1220" height="1939" alt="1000033967" src="https://github.com/user-attachments/assets/6dbb3171-baf6-4750-a01e-fa7b483b0666" />
<br>

As survival time increases, enemy spawn rates intensify and dynamic audio scaling kicks in to raise the tension. Players must balance real-time crystal repair clicks with tactical offensive strikes, earning points to buy persistent upgrades—such as increased Max HP, higher healing power, and boosted damage per click. Built without external dependencies or heavy libraries, Crystal Clicker offers an instant-loading, responsive, and engaging browser arcade experience.

---

## Key Features

* **Hybrid Gameplay Loop**: Combines active clicking mechanics with strategic wave-defense enemy scaling per minute.
* **Dynamic Escalation**: Enemy spawn rates, damage ticks, and background audio pitch/tempo scale automatically as survival time increases.
* **Modern Glassmorphism UI**: Custom neon aesthetics, responsive sidebars, animated click effects, and visual health indicators.
* **Upgrade Shop**: Purchase persistent stat upgrades including Max HP, Heal Per Click, Points Per Click, and Damage Per Click.
* **Real-time Stats Tracker**: Monitor active enemies, spawn rates, enemy health, and click power live during gameplay.
* **Lightweight & Fast**: Built with zero external dependencies, frameworks, or heavy libraries for instant load times.

## Tech Stack

* **HTML5**: Semantic UI layout and dynamic audio playback.
* **CSS3**: Responsive design with CSS Variables, Flexbox, backdrop blur effects, and custom keyframe animations.
* **JavaScript (ES6+)**: Core game engine, interval timers, state management, event handling, and DOM manipulation.
